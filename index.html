Review safeguards

Decor Areas Studio requests only the permissions needed for the features shown here. Pinterest API data is fetched on demand for the authorized account and is not used for competitor research, benchmarking, cross-account aggregation, off-Pinterest advertising, or AI model training.

Trial write testing is limited to Pinterest Sandbox. Users explicitly select each item they publish, and production publishing is used only when Pinterest grants the required access.
