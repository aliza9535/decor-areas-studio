Privacy Policy

Effective: September 24, 2026

Decor Areas Studio is an independent content publishing, scheduling and analytics service for creators and businesses.

Workspace accounts

If account services are enabled, we store the email address you provide, a one-way password hash, session records, your plan level and identifiers needed to manage your subscription. Passwords are not stored in plain text.

Pinterest authorization

Users connect their own Pinterest account through Pinterest's OAuth Authorization Code flow. We do not request or collect Pinterest passwords or Pinterest session cookies. For signed-in scheduler users, Pinterest access and refresh credentials are encrypted server-side so approved scheduled Pins can be published later without requiring the browser to remain open.

Pinterest information processed

At the user's request, the service may fetch the authorized account's profile information, Boards, Pins and organic analytics. Analytics is fetched on demand and is not used to build cross-account datasets. Publishing content may include an image or hosted image URL, title, description, destination URL, alt text, Board selection and requested schedule time.

Scheduling data

Scheduled Pin records are retained so the service can carry out the future publishing action that the user individually reviewed and approved. Records may include the publishing fields above, status, returned Pinterest Pin ID, error details and timestamps. Users can cancel queued items and can delete their workspace account.

Website import

The Blog → Pin tool fetches public webpage metadata from a URL supplied by the user, such as a title, description, canonical URL and Open Graph image. It does not use this feature to scrape Pinterest.

Payments

If paid plans are enabled, payment checkout is handled by Stripe. Decor Areas Studio stores subscription/customer identifiers and plan status needed to provide the service; card details are handled by the payment provider rather than stored by this application.

What we do not do

We do not scrape Pinterest, collect Pinterest login credentials, sell Pinterest API data, provide unauthorized competitor research or benchmarking, combine unrelated users' Pinterest data into a data product, use Pinterest API data for off-Pinterest advertising, or use Pinterest API data to train or improve AI or machine-learning models.

User control and deletion

Users can disconnect browser authorization from Settings, revoke the app from Pinterest account settings, cancel queued scheduled Pins, and delete the workspace account where that feature is enabled. See Data Deletion & Disconnection.

Relationship with Pinterest

Decor Areas Studio is an independent product. It is not an official Pinterest product and does not claim Pinterest Business Partner status unless Pinterest separately grants that status.

Security

See Security & Data Handling for an overview of the controls used by the service.
