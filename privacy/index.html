Privacy Policy

Effective: September 24, 2026

Decor Areas Studio is an independently branded content publishing, planning and analytics tool for creators and businesses. This policy describes the current Pinterest API integration and browser-only workspace features.

Pinterest authorization

Users connect their own Pinterest account through Pinterest's OAuth Authorization Code flow. Decor Areas Studio does not request or collect Pinterest passwords or Pinterest session cookies. OAuth credentials are encrypted before being stored in Secure, HttpOnly, SameSite first-party cookies and are not exposed to page JavaScript or displayed in the interface.

Information processed

When a user requests a feature, Decor Areas Studio may fetch the authorized account's profile information, Boards, Pins and organic analytics from the Pinterest API. For publishing, users may provide an image, title, description, destination URL, alt text and Board selection. Users can also provide their own article title, summary and URL to prepare editable Pin copy.

Storage and retention

The current application does not maintain a persistent server database of Pinterest API-derived account, Board, Pin or analytics data. Pinterest information is fetched on demand and displayed to the authorized user. OAuth credentials are stored only in encrypted first-party cookies. Draft and planner metadata created by the user may be stored in the browser's local storage on that device; this local workspace does not store Pinterest access tokens or a persistent copy of Pinterest API-derived analytics or account data. Uploaded images are not persisted in the local planner.

What we do not do

Decor Areas Studio does not scrape Pinterest, collect Pinterest login credentials, combine data across unrelated Pinterest accounts, provide unauthorized competitor research or benchmarking, sell Pinterest API data, use Pinterest API data for off-Pinterest advertising, or use Pinterest API data to train, fine-tune or improve AI or machine-learning models.

User control

Users can disconnect Pinterest from the Settings page, clear browser-only drafts and planner items, and revoke app authorization from Pinterest account settings. After authorization is removed, Decor Areas Studio cannot make new Pinterest API requests using that authorization.

Relationship with Pinterest

Decor Areas Studio is an independent product. It is not an official Pinterest product and does not claim Pinterest Business Partner status unless such status is separately granted by Pinterest.
