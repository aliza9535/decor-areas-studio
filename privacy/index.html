Privacy Policy

Effective: September 19, 2026

Decor Areas Studio is an independently branded content publishing and analytics tool for creators and businesses. This policy describes the current Pinterest API integration.

Pinterest authorization

Users connect their own Pinterest account through Pinterest's OAuth Authorization Code flow. Decor Areas Studio does not request or collect Pinterest passwords or Pinterest session cookies. OAuth credentials are treated as sensitive authentication data, encrypted before being stored in Secure, HttpOnly, SameSite first-party cookies, and are not exposed to page JavaScript or displayed in the interface.

Information processed

When a user requests a feature, Decor Areas Studio may fetch the authorized account's profile information, Boards, Pins and organic analytics from the Pinterest API. For publishing, users may provide an image, title, description, destination URL, alt text and Board selection.

Storage and retention

The current application does not maintain a persistent database of Pinterest API-derived account, Board, Pin or analytics data. That information is fetched on demand and displayed to the authorized user. User-supplied publishing content is processed to complete the requested API call and is not stored in an application database by this build.

What we do not do

Decor Areas Studio does not scrape Pinterest, collect Pinterest login credentials, combine data across unrelated Pinterest accounts, provide unauthorized competitor research or benchmarking, sell Pinterest API data, use Pinterest API data for off-Pinterest advertising, or use Pinterest API data to train or improve AI or machine-learning models.

User control

Users can disconnect the browser authorization session from the Settings page. Users can also revoke app authorization from their Pinterest account settings. After authorization is removed, Decor Areas Studio cannot make new API requests using that authorization.

Relationship with Pinterest

Decor Areas Studio is an independent product. It is not an official Pinterest product and does not claim Pinterest Business Partner status unless such status is separately granted by Pinterest.

Security

See our Security & Data Handling page for the controls used by this integration and our Data Deletion & Disconnection page for removal information.
