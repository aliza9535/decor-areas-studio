Data Deletion & Disconnection

Decor Areas Studio gives users direct control over the Pinterest authorization used by this browser.

Disconnect Decor Areas Studio

Open Settings in Decor Areas Studio and choose Disconnect Pinterest from this browser. This clears the Pinterest OAuth credentials held by this browser for Decor Areas Studio.

Revoke Pinterest authorization

Users can also review or revoke connected app access from Pinterest account settings. Once authorization is revoked, Decor Areas Studio cannot make new authorized Pinterest API requests with that authorization.

Stored Pinterest API data

The current application does not maintain a persistent database of Pinterest API-derived account, Board, Pin or analytics data. These values are fetched on demand. User-provided image and text content in the publishing demo is processed for the requested Pinterest API call and is not retained in an application database by this build.

Never send passwords, access tokens, refresh tokens or application secrets in a support or deletion request.
