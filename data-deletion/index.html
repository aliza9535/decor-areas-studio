Data Deletion & Disconnection

Decor Areas Studio provides controls for both Pinterest authorization and application account data.

Disconnect Pinterest from the browser

Open Settings and choose Disconnect browser. This clears Pinterest OAuth credentials held by the browser for Decor Areas Studio.

Revoke Pinterest authorization

You can also revoke connected app access from Pinterest account settings. Once authorization is revoked, new Pinterest API requests using that authorization can no longer succeed.

Cancel scheduled Pins

Open Scheduler and cancel any item that has not yet been published. Cancelled items will not be processed as due scheduled Pins.

Delete the workspace account

If workspace accounts are enabled, Settings includes Delete workspace account. Deleting the account removes the account record and associated application sessions, stored Pinterest OAuth record and scheduler records from the connected application database through cascading deletion.

Analytics data

Authorized Pinterest analytics is fetched on demand and is not persisted as a cross-account analytics database by this build.

Never send passwords, access tokens, refresh tokens or application secrets in a support or deletion request.
